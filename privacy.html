Privacy Policy

Zero-Data architecture and absolute confidentiality for your legacy code.

1. Zero Telemetry & Tracking

The Macondo desktop application does not collect, store, or transmit any diagnostic metrics, usage telemetry, crash logs containing code, or unique hardware identifiers.

2. 100% Offline & Local Processing

All project files (.vbp, .frm, .bas, .cls, .ctl), AST syntax tree resolution, Blast Radius computation, and disk caching reside solely on your machine. No source code snippets or project metadata are ever uploaded to cloud servers or third parties.

3. Transparent Update Checks

Macondo includes an optional update check that performs a simple, public HTTP GET request to download version.json from GitHub. No user data, device tokens, or environment details are transmitted during this request.

4. No Tracking Cookies on Website

This website is strictly informational and does not use profiling cookies, advertising cookies, or invasive analytics trackers (such as Google Analytics or marketing pixels). We do not collect personal data from visitors.

5. GitHub Pages Hosting

This website is hosted via GitHub Pages. While browsing, GitHub may log standard network connection metadata (such as IP addresses and user agents) strictly for security, routing diagnostics, and service integrity, governed by GitHub's Privacy Statement.
