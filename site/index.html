Comprehensive Analysis Suite

Every analytical lens to master your code.

Over 20 deterministic static analysis, architectural diagnostics, and risk evaluation tools built into a unified 100% offline environment.

2D Semantic Code Graph

Interactive 60 FPS vector canvas with 4 layout engines (Standard Radial, Affinity, Clustered Islands, and Force-Directed) and dynamic symbol expansion.

Screen Flow

Visual map of user interface navigation and transitions between Forms, dialogs, and windows, identifying entry points and screen chains.

Control Flow Graph (CFG)

Basic Block decomposition per routine showing execution paths, decision nodes, branch conditions, and looping structures.

Architectural Flow (Chord)

Circular Chord diagram quantifying call volumes and cross-layer interdependence across architectural layers, packages, and namespaces.

CodeCity 3D

Interactive 3D software city where buildings represent files/classes: height reflects LOC, base area reflects complexity, and color reflects risk.

Design Structure Matrix (DSM)

High-density square dependency matrix to instantly spot hidden couplings, feedback cycles, and recursive loops across modules.

Metrics Treemap

Hierarchical proportional treemap with interactive drill-down: instantly pinpoint where lines of code and cyclomatic complexity are clustered.

Martin Package Metrics

Rigorous computation of Afferent/Efferent Coupling (Ca, Ce), Instability (I), Abstractness (A), and Distance from the Main Sequence (D).

Cohesion & LCOM

Lack of Cohesion of Methods (LCOM4) scoring to identify bloated god-classes and Single Responsibility Principle violations.

Maintainability Index (MI)

Standard maintainability rating (0–100) computed from Halstead Volume, McCabe Cyclomatic Complexity, and effective code line counts.

Architectural Rules

Automated validation of architectural constraints (e.g. preventing the UI presentation layer from directly touching database storage).

Blast Radius & Risk Scoring

Recursive upstream caller tracing with automated regression risk scoring from Low to Critical and a navigable interactive audit grid.

Risk Hotspots

2D scatter plot correlating Cyclomatic Complexity with Change Frequency/Fan-in to highlight fragile components prone to regressions.

Dead Code & Orphan Routines

Automated detection and isolation of uncalled routines, unused classes, and orphan functions to trim bloat before migration.

Shared State & Globals

Exhaustive mapping of global and public variables with precise tracking of which routines read and write each shared variable.

Temporal Coupling (VCS)

Commit history mining to uncover modules that are not structurally linked but frequently change together over time.

Code Clones (CPD)

Token-based duplicate code detection to identify copy-pasted blocks, redundant logic, and refactoring candidates.

Data Flow & Taint Analysis

Tracking data propagation and variable state across method call boundaries to identify taint paths and sensitive data handling.

CRUD Matrix

Cross-reference matrix linking business routines with database tables, cataloging Create, Read, Update, and Delete operations.

API Diff & SemVer

Semantic comparison across code revisions to identify breaking changes, method signature alterations, and public API additions.

Social Code & Bus Factor

VCS authorship and code ownership distribution analysis to calculate Bus Factor and mitigate developer knowledge silos.
CI/CD, AI & Modernization

The ideal bridge between legacy code, pipelines, and modern AI.

Extract compact, structured Markdown and JSON Repo Maps ready for Claude, ChatGPT, Gemini, Copilot, Cursor, or run automated quality audits in your CI/CD pipelines (GitHub Actions, Azure DevOps) to accelerate refactoring and modernization into modern C#/.NET.

  • Targeted subgraphs that minimize token noise and maximize LLM accuracy.
  • Zero hallucinations: the LLM receives verified AST, CALLS relationships, and resolved types.
  • Headless CLI execution for CI/CD Quality Gates or as a tool for autonomous AI agents (Claude Code, Cursor, Antigravity, MCP, etc.).
Macondo CLI • Terminal
# 1. Compact Repo Map for Claude, ChatGPT, Cursor & Antigravity
Macondo.exe analyze "C:\Projects\CoreBackend\Core.csproj" --export-md "repo-map.md"
# 2. Comprehensive 20+ Tool Audit Report (Markdown or JSON)
Macondo.exe analyze "C:\Projects\LegacyApp\App.vbp" --report "audit-report.md"
# 3. Targeted Blast Radius calculation on a specific routine or class
Macondo.exe analyze "C:\Projects\App" --impact "ProcessOrder" "blast-radius.md"
# 4. Batch export of all analytical reports to an output folder
Macondo.exe analyze "C:\Projects\ERP" --out-dir ".\reports" --format all
# 5. CI/CD Quality Gate (fail build if MI < 65 or architectural rules break)
Macondo.exe analyze "Solution.sln" --fail-on-violations --fail-on-mi 65
